# AI Command Center

A desktop application built with Tauri + React + TypeScript.

## Tech Stack

- **Frontend**: React 18 + TypeScript + Vite
- **Backend**: Tauri 2 (Rust)
- **Linting**: ESLint
- **Type Checking**: TypeScript

## Development

```bash
# Install dependencies
npm install

# Run in development mode
npm run dev

# Build for production
npm run build

# Lint
npm run lint

# Type check
npm run typecheck
```

## Tauri Commands

```bash
# Run Tauri in development
npm run tauri dev

# Build Tauri app
npm run tauri build
```
